# URGENCES — simulateur de service d'urgences (Godot 4.4)

Projet en cours de développement. Voir `GUIDE.md` (à venir) pour l'installation.

- Moteur : Godot 4.4.1, rendu Forward+ (Vulkan), GDScript.
- Ressources : générées par les outils de `tools/` (textures PBR procédurales, mobilier modélisé
  par script Blender, personnages construits à partir des données CC0 de MakeHuman, animations
  reciblées depuis la base de capture de mouvement de Carnegie Mellon University).
